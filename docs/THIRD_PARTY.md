# 글꼴과 제3자 자료

한글 글리프에 사용한 글꼴의 원 저작권과 라이선스를 유지합니다.

- **GNU Unifont 17.0.05** — 12×12 한글과 일부 제목 글리프의 원본. [라이선스](../third_party/unifont/LICENSE.txt), [OFL 1.1](../third_party/unifont/OFL-1.1.txt).
- **갈무리 Galmuri7 v2.40.4** — 8×8 셀의 작은 한글 버튼. [OFL 1.1 및 저작권 표기](../third_party/galmuri/OFL-1.1.md).
- **Neo둥근모 v1.601** — 메인 메뉴용 큰 한글 글리프. [OFL 1.1 및 저작권 표기](../third_party/neodgm/LICENSE.txt).

패치에 포함되는 글꼴 유래 도트에는 각 원본 글꼴의 이용 조건이 적용됩니다.
글꼴 원본 파일은 이 패키지에 포함하지 않습니다.

Mednafen/Beetle PC-FX와 Python/Pillow는 제작·검증에 사용했습니다.
에뮬레이터 실행 파일은 배포하지 않으며, 확인용 패치 적용 도구는 Python 표준 라이브러리만 사용합니다.

PC-FX BIOS, 게임, Kodak Photo CD 사진 및 원작 화면의 권리는 각 권리자에게 있습니다.
