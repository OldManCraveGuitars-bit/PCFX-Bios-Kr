# 1.0 검증 안내

## 원본 일본어 글꼴 보존

BIOS의 원래 글꼴 조회 함수가 참조하는 6종의 글꼴 영역을 원본과 직접 비교했습니다.
**총 370,560바이트가 동일하며, 기존 일본어 글꼴을 삭제하거나 한글로 교체하지 않았습니다.**
글꼴의 빈 문자 영역도 원본 바이트로 보존합니다. 한글은 별도 데이터로 추가했습니다.

| 원본 글꼴 번호 | ROM 시작 위치 | 비교 바이트 | 결과 |
| --- | --- | ---: | --- |
| 0 | `0x95950` | 229,186 | 원본과 동일 |
| 1 | `0xCD894` | 129,086 | 원본과 동일 |
| 2 | `0xED0D4` | 4,096 | 원본과 동일 |
| 3 | `0xEE0D4` | 3,072 | 원본과 동일 |
| 4 | `0xEECD4` | 2,048 | 원본과 동일 |
| 5 | `0xEF4D4` | 3,072 | 원본과 동일 |

각 영역의 SHA-256과 결과 ROM의 확인값은 [verification.json](verification.json)에 있습니다.
게임이 BIOS 글꼴을 읽을 때 원래의 글꼴 데이터를 사용할 수 있도록 보존한 것입니다.
모든 게임의 모든 BIOS 호출과 실기기를 전수 검사했다는 뜻은 아닙니다.

## 확인한 실행 경로

Beetle PC-FX/libretro 기반의 격리된 에뮬레이터 실행에서 확인했습니다.

- 파일 관리 진입, 본체 데이터 선택, 삭제·초기화 확인창 표시.
- 예 / 아니오의 취소·실행 동작. 원본 세이브는 바꾸지 않고 에뮬레이터의 복사본으로 확인.
- 복사·이동의 용량 부족 안내, 확인 버튼과 하단 도움말.
- CD 재생기의 시간 표시 항목과 종료 후 메인 메뉴 복귀.
- Kodak Photo CD의 갤러리·사진 표시, 한글 버튼과 커서 도움말.
- 포토 CD가 아닌 디스크의 최초 안내와 대기 후 교체 안내. 3,600프레임까지 관찰.
- 원본 랑그릿사 FX의 부팅과 오프닝 진입.

파일 관리 동작 및 게임 부팅은 마지막 포토 CD 문구 수정 전에도 검증했으며,
정식판에서 파일 관리 모듈이 그 검증본과 동일함을 비교했습니다.
최종 배포 내용으로 파일 관리 스크린샷을 새로 촬영하고, 사진 CD 진입과
CD 재생기 종료도 다시 실행했습니다.

## 배포 파일 검증

- IPS를 지원 원본 BIOS에 적용한 결과가 배포 대상으로 확정한 ROM과 완전히 일치.
- 원본 및 결과 크기는 모두 1,048,576바이트.
- 원본 글꼴 6종과 글꼴 표의 보존 확인.
- 공개 패키지에 BIOS ROM, 게임 이미지, 세이브, 에뮬레이터 실행 파일을 포함하지 않음.

## 검증 범위

1.0은 정식 배포 버전입니다. 실기기와 전 게임·장시간 플레이는 전수 검증하지 않았습니다.
발견한 문제가 있으면 기기·에뮬레이터, 메뉴, 재현 순서와 대기 시간을 함께 제보해 주세요.
