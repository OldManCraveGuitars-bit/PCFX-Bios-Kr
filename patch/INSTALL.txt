[IPS 적용]
1. 원본 BIOS를 별도로 보관합니다.
2. 일반 IPS 패처에서 원본 pcfx.rom과 PCFX-Bios-Kr-v1.0.ips를 선택합니다.
3. 새 파일로 결과를 저장합니다. 이전 한글 패치 ROM에는 덧씌우지 마세요.
4. 에뮬레이터에서 결과 BIOS를 사용하도록 지정합니다.
   pcfx.rom 이름이 필요한 에뮬레이터에서는 출력 파일 이름을 맞춥니다.
5. 에뮬레이터를 완전히 종료하고 새로 부팅합니다.
   이전 상태 저장을 불러오면 예전 화면·문구가 남을 수 있습니다.

[Python 3 확인용 패처]
ZIP 압축을 푼 폴더에서 다음과 같이 실행합니다.
python patch/apply_patch.py 원본/pcfx.rom 결과/pcfx_kr.rom
공백이 들어간 경로는 따옴표로 감싸 주세요.
원본과 IPS, 결과 해시를 확인하며 기존 출력 파일은 덮어쓰지 않습니다.
추가 Python 패키지는 필요하지 않습니다.
