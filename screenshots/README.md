# 스크린샷

1.0 배포 대상과 같은 BIOS 내용으로 실행한 에뮬레이터 화면입니다.
메인 메뉴·CD 재생기·포토 CD 및 파일 관리 화면을 수록했습니다.

글자나 그래픽을 합성하지 않았습니다. 원본 캡처는 화면에 따라 256×240 또는
1024×240이므로, 보기 쉽도록 4:3 화면비의 768×576 PNG로 변환했습니다.
확대에는 최근접 보간을 사용했습니다. 원본 크기와 캡처 해시는 [captures.json](captures.json)에 있습니다.

파일 관리에는 검증용으로 복사한 Langrisser FX 저장 데이터를 사용했습니다.
사진 CD 화면에는 사용자가 제공한 Kodak Photo CD 디스크의 사진이 표시됩니다.
스크린샷 속 원작 그래픽과 사진에는 프로젝트의 MIT 라이선스가 적용되지 않습니다.
